# Users and Groups

This section demonstrates identity lifecycle and access-control concepts within the DomConsultancy on-premises Active Directory environment.

The objective is to create realistic user identities, security groups, and group memberships that can later support access-control testing and hybrid identity integration with Microsoft Entra ID.

## Objectives

- Create standard DomConsultancy user accounts
- Organise users within the appropriate Organizational Units
- Create security groups based on business functions
- Assign users to security groups
- Demonstrate group-based access control
- Apply least-privilege principles
- Prepare identities for future hybrid synchronization with Microsoft Entra ID
