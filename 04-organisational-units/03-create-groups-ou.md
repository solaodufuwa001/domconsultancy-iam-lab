## 3. Create the Groups OU

A `Groups` Organisational Unit was created inside the `DomConsultancy` root OU.

The `Groups` OU will be used to organise security and distribution groups separately from user accounts.

Separating groups into a dedicated OU provides a structured foundation for:

- Group-based access control
- Role-based access management
- Group Policy management
- Delegated administration
- Clear separation of identity objects

### IAM and Security Relevance

Dedicated group organisation supports the principle of structured identity management.

Security groups can later be used to assign permissions to resources without assigning permissions individually to users.

This supports scalable access management and helps reduce excessive direct permissions.
