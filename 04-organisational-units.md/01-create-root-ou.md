# Create the DomConsultancy Root OU

A root Organisational Unit named `DomConsultancy` was created within the `domconsultancy.local` Active Directory domain.

The root OU provides a logical container for organising the company's users, groups, computers, and administrative accounts.

The OU structure will allow different security controls and Group Policies to be applied to specific categories of objects.
