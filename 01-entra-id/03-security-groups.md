# Task 3 — Create Security Groups

## Objective

Create a security group to manage access for users belonging to the Finance department.

## Configuration

| Setting | Value |
|---|---|
| Group type | Security |
| Group name | DomConsultancy-Finance |
| Membership type | Assigned |
| Member | Alice Johnson |
| Purpose | Finance access management |

## Result

Successfully created the DomConsultancy-Finance security group and added Alice Johnson as a member.

## IAM Principle

Security groups provide a scalable way to manage access.

Users can be assigned to groups based on their department or role, allowing permissions to be managed at the group level rather than individually.

This approach simplifies access management and supports scalable identity administration.
