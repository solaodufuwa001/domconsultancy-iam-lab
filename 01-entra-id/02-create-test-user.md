# Task 2 — Create Test User

## Objective

Create a fictional employee account to practise Identity and Access Management within Microsoft Entra ID.

## User Created

| Field | Value |
|---|---|
| Name | Alice Johnson |
| Department | Finance |
| Job title | Finance Analyst |
| Account type | Member |
| Purpose | IAM lab/testing |

## Result

Successfully created the Alice Johnson test account in Microsoft Entra ID.

## Security Consideration

A separate test identity was used instead of the administrator account for normal user activities.

This supports the principle of least privilege and allows access controls to be tested safely.
