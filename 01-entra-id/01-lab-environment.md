# Task 1 — Lab Environment

## Objective

Create and establish the Microsoft Entra ID environment that will be used throughout the DomConsultancy Identity and Access Management lab.

## Lab Environment

| Component | Configuration |
|---|---|
| Organisation | DomConsultancy |
| Identity Platform | Microsoft Entra ID |
| Entra Licence | Microsoft Entra ID Free |
| Environment Type | IAM Training / Test Lab |
| Purpose | Identity and Access Management testing |

## Lab Purpose

The DomConsultancy Microsoft Entra tenant was established as a dedicated training environment for practising Identity and Access Management concepts.

The environment was used to safely test:

- User and group management
- Role-Based Access Control (RBAC)
- Least privilege
- Multi-Factor Authentication (MFA)
- Sign-in monitoring
- Audit logging
- Conditional Access concepts
- Group-based access control

All identities used within the lab were fictional test accounts.

## Security Consideration

A dedicated lab environment was used to avoid performing testing against production identities or systems.

Test accounts were used throughout the exercises so that administrative roles, authentication controls and access-management scenarios could be safely validated.
